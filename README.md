# Cybersecurity & Infrastructure Laboratory Reports

This repository contains five university laboratory reports covering cybersecurity, security monitoring, Linux infrastructure, and automation.

> **Privacy notice:** The published PDF copies are privacy-sanitized. Student numbers, identifiable local hostnames, and illustrative lab credentials have been permanently redacted. Sensitive values were removed from the PDF content, not merely concealed with visual overlays. Command examples containing redacted demo values need to be configured with your own safe test credentials before being run.

## Reports

| Report | Focus |
| --- | --- |
| [WAF Detection and Log Analysis](reports/WAF_Detection_and_Log_Analysis.pdf) | SafeLine WAF, DVWA (Docker), wafw00f, Nmap, nuclei, log analysis |
| [Windows Logs with Graylog](reports/Windows_Logs_Graylog_Dashboard.pdf) | Windows Event Logs, NXLog, GELF UDP, centralized dashboards |
| [MITRE Caldera Windows Artefact Analysis](reports/MITRE_Caldera_Windows_Artefact_Analysis.pdf) | Controlled MITRE Caldera simulation, Sysmon, PowerShell, forensic event correlation |
| [SNMP Monitoring with Grafana](reports/SNMP_Telegraf_InfluxDB_Grafana.pdf) | SNMP, Telegraf, InfluxDB, Grafana metric collection and dashboards |
| [Wazuh + n8n Threat Detection](reports/Wazuh_n8n_Threat_Detection_and_Notification.pdf) | Wazuh alerts, Python integration, n8n webhook notification pipeline |

## Environment and scope

These academic reports document experiments carried out in isolated or personally controlled laboratory environments. They are shared for educational and portfolio purposes, not as production-ready configurations or instructions for testing systems without authorization.
